# keenanlk/homebrew-tap

Homebrew casks for [ShipBoard](https://shipboardapp.com/) — a free macOS menu-bar app that shows AWS CodePipeline, GitHub Actions, GitLab CI, Vercel and Netlify status on one board.

```sh
brew install --cask keenanlk/tap/shipboard
```

ShipBoard updates itself (Sparkle), so `brew upgrade` isn't needed; the cask is bumped on each release.
